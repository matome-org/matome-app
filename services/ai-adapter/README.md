# Matome audio adapter

The adapter implements Matome's versioned AI processor contract while delegating
audio transcription to a synchronous Whisper-compatible API. It advertises only
the `audio` input and `transcript` output; Core therefore records other enabled
input kinds as `not_available` instead of dispatching unsupported work.

## Contract flow

```text
Core -- GET /v1/capabilities --> adapter
Core -- POST /v1/jobs --------> durable accepted-job store -- 202 --> Core
                                      |
                                      +-- GET job.input.media.url
                                      +-- verify byte size and SHA-256
                                      +-- ffmpeg to 16 kHz mono WAV
                                      +-- POST multipart to audio API
                                      +-- retry exact terminal callback payload --> Core
```

The dispatch bearer token authenticates capability and job requests. Callback
authorization is copied from `job.callback.headers.authorization`; it is the
independent per-run identity generated by Core, never the dispatch credential.
Accepted jobs and terminal callback payloads are atomically persisted before
acknowledgement/delivery, so restarting with the same data directory resumes
work without creating a second terminal result.

## Run locally

```sh
AI_ENGINE_DISPATCH_TOKEN=dev-ai-dispatch-token \
AUDIO_API_ENDPOINT=http://localhost:8000/api/v1/transcribe \
AI_ADAPTER_DATA_DIR=/tmp/matome-ai-adapter-jobs \
AI_ADAPTER_PORT=7005 \
node services/ai-adapter/src/server.js
```

Point Core's `AI_ENGINE_ENDPOINT` at `http://host.docker.internal:7005/v1/jobs`
for local development. Core's callback base URL must be reachable by the host
adapter.

## Environment

| Variable | Local default | Notes |
| --- | --- | --- |
| `AI_ENGINE_DISPATCH_TOKEN` | empty | Must match Core's outbound dispatch token. Production requires a non-default value of at least 32 bytes. |
| `AUDIO_API_ENDPOINT` | `http://localhost:8000/api/v1/transcribe` | Whisper-compatible endpoint. Production requires HTTPS. |
| `AI_ADAPTER_DATA_DIR` | OS temp directory | Durable job/callback state. Required explicitly in production. |
| `AI_ADAPTER_HOST` | `0.0.0.0` | Bind host. |
| `AI_ADAPTER_PORT` | `7005` | Listen port. |

Production jobs also reject non-HTTPS media or callback URLs. Logs contain only
job/run identities and stable error codes, never input content, callback
credentials, or presigned URLs.
