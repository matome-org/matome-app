# Matome App

Matome is a React Native mobile app built with Expo. It records audio, transcribes content through an external API, and stores recordings locally with SQLite.

## Quick Start

```bash
bun install
npx expo start
npx expo start --ios
npx expo start --android
npx expo lint
```
