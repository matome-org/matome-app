# Install and remove Matome

Choose the package for your device in the [README](../README.md#install).

## Windows

Open the downloaded installer and follow its prompts. To remove Matome, open
**Settings → Apps → Installed apps**, find **Matome**, and choose
**Uninstall**.

## macOS

Open the DMG and drag **Matome.app** to **Applications**. To remove Matome,
quit the app and move it from Applications to the Trash.

## Linux

Download the AppImage, allow it to run as a program in your file manager's
permissions, and open it. From the directory where you downloaded it, you can
also run:

```bash
chmod +x matome-linux-x86_64.AppImage
./matome-linux-x86_64.AppImage
```

Keep the AppImage wherever you prefer. To remove Matome, delete that file.

## Android

Open the APK on an arm64 Android device and follow the installation prompts.
Android may ask you to allow APK installation from the app you used to open
the file. To remove Matome, open **Settings → Apps → Matome → Uninstall**.

The macOS and Windows desktop packages are currently unsigned. Those systems
may show a security warning when you open the download. Removing the app does
not delete documents stored in Matome Core.
